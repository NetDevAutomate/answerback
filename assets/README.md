# Answerback identity

The mark is a square cut by a stepped seam into two identical halves, like a split
tally stick: each party kept one half, and the record was proved when the halves
fitted. It stands for a reply that counts only when it matches the request. The
halves are interchangeable, so the mark belongs to no single host. Sage green
matches the live monitor.

Hand-made sources:

- `mark.svg`: the mark on a 64-unit grid. Every edge sits on a multiple of 4, so it
  stays crisp at 16 px.
- `wordmark.svg`: "answerback" in Noto Sans Mono Bold, converted to outlines.
- `tagline.svg`: the tagline in Noto Sans Mono Regular, converted to outlines.

Generated by `scripts/build_brand.py`:

- `logo.svg` / `logo-dark.svg`: lockups for light / dark backgrounds, 410 × 88.
  `logo.png` / `logo-dark.png` are transparent 1640 × 352 copies for places that
  do not take SVG.
- `icon-16.png` to `icon-256.png`: the mark on its rounded tile.
- `avatar.svg` / `avatar.png`: full-bleed 512 × 512 square for GitHub avatars.
  GitHub rounds it or crops it to a circle, so the glyph is drawn smaller.
- `favicon.ico` and `bus/assets/favicon.svg`: browser icons for the live monitor.
- `social-preview.svg` / `social-preview.png`: 1280 × 640 GitHub social preview.

GitHub controls its own browser favicon. Upload the social preview under repository
Settings → General → Social preview if desired. Creating these assets does not
change any GitHub setting or repository name.

Regenerate with `uv run python scripts/build_brand.py` after installing the development
dependencies and Chromium (`uv run playwright install chromium`). The lettering is
already outlined, so no font is needed. To change the wording or the typeface, redraw
`wordmark.svg` or `tagline.svg`; the script only composes and rasterises.
